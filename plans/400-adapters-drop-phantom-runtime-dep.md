## Why this matters

Both manifests declare `"@lunora/runtime": "1.0.0-alpha.68"` as a runtime dependency, but no source file in either package imports it — `@lunora/react` and `@lunora/solid`, with identical adapter surfaces, don't declare it. The cost is real: independent per-package semantic-release means every `@lunora/runtime` release forces a no-op `@lunora/vue`/`@lunora/svelte` release (vue is ~30 alpha releases ahead of react, largely dependency-bump churn — `packages/vue/CHANGELOG.md` shows nine consecutive `**@lunora/runtime:** upgraded` entries), and it pulls the server-side Worker/DO runtime into every Vue and Svelte app's install graph.
