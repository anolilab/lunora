(Fable) append findings here; fixers (Opus) close them. One row per finding.

Status: `open` → `fixing` (agent assigned) → `fixed` (in tree, uncommitted) →
`pr` (in a PR, column says which) → `merged`. `wontfix` carries a reason.

Severity: H (data loss / security / money), M (wrong answer, silent), L (edge,
wording, hygiene).
