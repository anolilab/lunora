cirrus/messages.ts 
import { query, mutation } from "@cirrus/server"

// realtime by default — subscribers update on write
export const list = query({
  handler: async (ctx) => {
    return ctx.db.query("messages")
      .order("desc").take(50)
  },
})

export const send = mutation({
  args: { body: v.string() },
  handler: async (ctx, { body }) => {
    await ctx.db.insert("messages", { body })
  },
})
01 — The mark

The triple streak

Three thin strokes, long → medium → short. It reads as speed, as the layers underneath (Worker · Durable Object · D1), and as the trailing edge of a cirrus cloud. Monochrome only — ink on light, paper on dark. Never orange.

06 — Guardrails

Do & don't

Do

  • Keep the aerial-blue accent to one hook per surface.
  • Set the wordmark lowercase, always — cirrus.
  • Give the mark room — at least one stroke-width of space.
  • Pair tight Inter Tight headings with mono labels.

Don't

  • Tint the mark Cloudflare orange — or any orange.
  • Reorder, equalise or invert the three streaks.
  • Add a glow, bevel or gradient to the mark itself.
  • Lock the wordmark into uppercase or title case.
