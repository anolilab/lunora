Lunora ships as a set of focused, independently versioned `@lunora/*` packages. Install the unscoped [`lunorash`](/docs/packages/lunorash) umbrella for the base (server, values, runtime, Durable Objects, client) in a single dependency, then add only the opt-in packages you need. (The CLI bin stays `lunora`; the npm name is `lunorash` because `lunora` is already taken.)

<Callout type="info">Lunora is in **alpha**. The packages below are usable today, but APIs can still change between releases.</Callout>
