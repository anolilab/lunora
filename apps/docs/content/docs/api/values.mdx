`@cirrus/values` is the **single source of truth** for runtime validation and
the corresponding TypeScript type inference. `@cirrus/server` re-exports the
`v` namespace, so you almost always import these from `@cirrus/server` in
application code. You import this package directly only when writing a
shared validators library or testing validation in isolation.

```ts
import { type Infer, v, ValidationError } from "@cirrus/values";

const message = v.object({
    channelId: v.id("channels"),
    text: v.string(),
    pinned: v.optional(v.boolean()),
});

type Message = Infer<typeof message>;
//   ^? { channelId: Id<"channels">; text: string; pinned?: boolean }
```

## Validator factory (`v.*`)

| Factory                | Accepts                       | Description                              |
| ---------------------- | ----------------------------- | ---------------------------------------- |
| `v.string()`           | `string`                      | UTF-8 text                               |
| `v.number()`           | `number`                      | Finite JS number; **NaN throws**         |
| `v.boolean()`          | `boolean`                     | `true` / `false`                         |
| `v.null()`             | `null`                        | Only `null`                              |
| `v.bigint()`           | `bigint`                      | Stored as INTEGER in D1, lossless        |
| `v.bytes()`            | `ArrayBuffer` / `Uint8Array`  | Binary; rendered to BLOB in D1           |
| `v.any()`              | anything                      | Escape hatch — disables runtime checks   |
| `v.id(table)`          | `Id<table>`                   | Branded ID for the given table           |
| `v.literal(value)`     | exact `value`                 | String / number / boolean / null literal |
| `v.array(inner)`       | `Array<Infer<inner>>`         | Homogeneous array                        |
| `v.object(shape)`      | `{ ...shape }`                | Plain object; extra keys throw           |
| `v.union(a, b, ...)`   | any member                    | Discriminated by `kind` if present       |
| `v.optional(inner)`    | `Infer<inner>` \| `undefined` | Marks a field as nullable                |
| `v.record(key, value)` | `Record<key, value>`          | Map-style                                |

Each call returns a `Validator` whose `.validate(value)` throws
[`ValidationError`](#validationerror) on mismatch.

## `Id<TableName>`

A nominally-typed string brand. The `cirrus/_generated/dataModel.ts` file
re-exports `Id` so consumers can type their own helpers:

```ts
import type { Id } from "@/cirrus/_generated/dataModel";

const acl = (userId: Id<"users">) => {
    /* ... */
};
```

`Id<T>` does **not** carry the table name at runtime — it's compile-time
only. Reach for `v.id("users")` if you need the runtime check too.

## `Infer<T>`

Given a `Validator`, expand it to the inferred TypeScript type:

```ts
type T = Infer<typeof v.object({ foo: v.string() })>;
//   ^? { foo: string }
```

## `ValidationError`

Thrown by `.validate(value)` and surfaced by `query` / `mutation` / `action`
when the input shape doesn't match the declared args. Carries:

- `path: ValidationPath` — array of keys/indexes to the offending field
- `formatPath(path)` — render the path as `args.<field>.<sub>`
- `describeValue(value)` — short summary used in error messages

## `ValidatorKind`

String union of every supported kind — useful for switch-based reflection
(`@cirrus/codegen` uses it to map validators → SQL types).
