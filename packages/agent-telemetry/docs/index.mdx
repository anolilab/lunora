`@lunora/agent-telemetry` gives `@lunora/agent` observability. Each export produces a Vercel AI SDK `Telemetry` integration you drop into an agent's `telemetry.integrations`, so every LLM turn and tool call in the durable agent loop is traced.

- **`consoleTelemetry`** — a **zero-dependency** structured console tracer.
- **`combineTelemetry`** — fan the lifecycle out to several integrations and **nest** their span wrappers.
- **`sentryTelemetry`** / **`braintrustTelemetry`** — **dependency-injected** bridges: you pass your own initialized Sentry namespace / Braintrust logger, so the heavy vendor SDK is never imported here.

## Privacy-safe by default

Every integration accepts `recordInputs` and `recordOutputs`, both defaulting to **`false`**. Without an explicit opt-in, no prompt, message, tool argument, generated text, or tool result is forwarded — only structural metadata (model id, finish reason, token counts, tool name, timing, success/failure).

## Install

```sh
pnpm add @lunora/agent-telemetry
```

`consoleTelemetry` and `combineTelemetry` have zero runtime dependencies. `sentryTelemetry` / `braintrustTelemetry` expect you to pass in your own SDK instance, so install those SDKs only if you use those bridges.

## Usage

Wire an integration into your agent's `telemetry` — the same `TelemetryOptions` the AI SDK's `generateText` accepts:

```ts
import { defineAgent } from "@lunora/agent";
import { consoleTelemetry } from "@lunora/agent-telemetry";

export const support = defineAgent({
    name: "support",
    telemetry: {
        isEnabled: true,
        integrations: [consoleTelemetry({ functionId: "support" })],
    },
    // ...model, tools, loop control
});
```

### Combine several tracers

`combineTelemetry` returns one `Telemetry` that fans every callback out to all integrations and nests the two execution wrappers (`executeLanguageModelCall`, `executeTool`) right-to-left — the first integration is outermost, and a plain `execute` still runs if no integration wraps it.

```ts
import { combineTelemetry, consoleTelemetry, sentryTelemetry } from "@lunora/agent-telemetry";
import * as Sentry from "@sentry/cloudflare";

telemetry: {
    isEnabled: true,
    integrations: [combineTelemetry(sentryTelemetry({ Sentry }), consoleTelemetry())],
}
```

### Sentry (dependency-injected)

Model calls and tool executions become Sentry spans (`op: "gen_ai.generate"` / `"gen_ai.execute_tool"`) so nested provider/tool work is correctly parented; errors route to `Sentry.captureException`. Attributes carry only structural metadata unless `recordInputs` is set.

```ts
import { sentryTelemetry } from "@lunora/agent-telemetry";
import * as Sentry from "@sentry/cloudflare";

const integration = sentryTelemetry({ Sentry, functionId: "support" });
```

### Braintrust (dependency-injected)

Model calls (`type: "llm"`) and tool executions (`type: "tool"`) become `logger.traced` spans. Inputs are logged only with `recordInputs`, outputs only with `recordOutputs`.

```ts
import { braintrustTelemetry } from "@lunora/agent-telemetry";
import { initLogger } from "braintrust";

const logger = initLogger({ projectName: "support" });
const integration = braintrustTelemetry({ logger, recordInputs: true, recordOutputs: true });
```

## API

- `consoleTelemetry(options?)` — `{ logger?, functionId?, recordInputs?, recordOutputs? }`.
- `combineTelemetry(...integrations)` — merge integrations; nests wrappers right-to-left.
- `sentryTelemetry({ Sentry, functionId?, recordInputs?, recordOutputs? })` — dependency-injected Sentry bridge.
- `braintrustTelemetry({ logger, functionId?, recordInputs?, recordOutputs? })` — dependency-injected Braintrust bridge.
- Types: `SentryLike`, `SentryTelemetryOptions`, `BraintrustLike`, `BraintrustSpan`, `BraintrustTelemetryOptions`, `ConsoleLogger`, `ConsoleLogLevel`, `ConsoleTelemetryOptions`, `CommonOptions`.
